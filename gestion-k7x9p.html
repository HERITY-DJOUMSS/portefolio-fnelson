// Comment configurer n8n pour recevoir les avis :

1. Va sur app.n8n.cloud ou ton instance n8n
2. Crée un nouveau workflow → Ajoute un nœud Webhook
3. Configure : Method = POST, Path = portfolio-avis
4. Copie l'URL du webhook → colle-la ci-dessus
5. Ajoute un nœud Gmail / Email après le webhook
6. Dans l'email : Subject = Nouvel avis portfolio, Body = {{$json.nom}} : {{$json.message}} — Note : {{$json.note}}/5
7. Active le workflow → Teste en soumettant un avis sur le portfolio

// Comment configurer JSONBin.io (gratuit) :

1. Va sur jsonbin.io → crée un compte gratuit
2. Dashboard → API Keys → copie ta Master Key
3. Crée un nouveau Bin → New Bin → colle {} → Save
4. Copie l'ID du Bin (dans l'URL ou l'encadré)
5. Colle Bin ID et Master Key ci-dessus → Enregistrer
6. Clique "Pousser mes données" depuis ton PC
7. Sur ton téléphone → ouvre l'admin → "Récupérer depuis le cloud" → tes données apparaissent !
